# Microsoft Store Capability Justifications

Copy and paste the text below into the submission form in the Microsoft Partner Center.

---

## 1. Capability: location
**Justification:**
Oasis is a social collaboration platform that allows users to optionally share their current location for home check-ins, local event coordinates, and location-tagged status updates. Access to location APIs is required to retrieve and display coordinates on interactive maps when the user explicitly requests to share their location.

---

## 2. Capability: microphone
**Justification:**
Oasis provides real-time voice and video calling features as well as voice transcript recordings. The application requires microphone access to record audio messages, capture voice input for transcription services, and transmit user audio during active calls.

---

## 3. Capability: webcam
**Justification:**
Oasis allows users to take and share photos directly from the app. Webcam access is necessary for capturing user profile pictures, recording stories, and sharing real-time photos and video streams during active calls.
