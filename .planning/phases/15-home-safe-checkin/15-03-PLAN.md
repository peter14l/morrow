    Create lib/services/home_checkin_service.dart:
    
    Core Methods:
    - checkIn(): User confirms they are home
      - Sends "❤️ [Username] has reached home" notification to partner
      - Triggers heartbeat haptic pattern
      - Stores checkIn timestamp
    - verifyCheckIn(wasAccurate: bool): User says whether location was accurate
      - If wasAccurate = false: Send warning to partner
      - Stores verification result
    - notifyPartnerReachedHome(String partnerId): Send FCM notification
      - Uses existing NotificationManager for sending
      - Message: "❤️ [Username] has reached home"
    - notifyPartnerNotReachedHome(String partnerId): Send warning notification
      - Message: "⚠️ [Username] has not actually reached home"
    
    External Dependencies:
    - Partner ID from couple_bubbles table (Phase 14)
    - FCM token from profiles table
    - NotificationManager for push sending
    
    IMPORTANT: Home location is never sent to server - only the "at home" state is communicated.

    New method 'heartbeatPulse()':

    - Creates 3 short pulses like a heartbeat (60 BPM feel)
    - Use HapticFeedback.lightImpact() with delays between
    
    New method 'homeArrivedVibration()':
    - Longer, celebratory pattern for "reached home"
    - light → medium → heavy → medium → light (escalating)
    
    New method 'warningPulse()':
    - Different pattern for "did not reach home" warning
    - Heavy impact × 2 with short delay
    
    Add these to HapticUtils class:
    ```dart
    static Future<void> heartbeatPulse() async {
      await HapticFeedback.lightImpact();
      await Future.delayed(const Duration(milliseconds: 100));
      await HapticFeedback.lightImpact();
      await Future.delayed(const Duration(milliseconds: 100));
      await HapticFeedback.lightImpact();
    }
    ```
